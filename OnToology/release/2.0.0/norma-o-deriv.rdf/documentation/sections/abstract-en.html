Abstract

NORMA-O Derivation (normad) is a companion module to NORMA-O 2.0 for describing derived normative graphs. NORMA-O states what norms say, how they relate and how they defeat one another; this module states what was concluded from a given set of norms and cases, by which activity and rule set, and under which assumptions.

It records each run of a rule set as a PROV-O activity, the prevalence orderings it computed over the whole body of norms or for one described case, the evaluation of each norm with its prevalence level, applicability status and the parties it reaches, and the cycles found among defeat relations together with their legal reading. Because derived conclusions depend on non-monotonic readings, such as treating the graph or the case description as closed, every activity declares the assumptions it relied on. A derived graph is thereby reproducible, explainable and never mistaken for annotated fact.
